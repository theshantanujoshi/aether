# Evidence and privacy contract

For each claim, distinguish the source itself, the agent's inference, and an observed check. A filename, note, or terminal command may support a chronology; it does not by itself prove an accomplishment, decision, or intent. Keep a source path or user-supplied identifier for each material claim without copying sensitive content into reports.

For a repository graph, containment comes from the file inventory. A reference edge needs a matching path or skill name found in a file. Do not draw import, call, or runtime edges from proximity or naming. Layout coordinates and node color carry no evidence. Report revision, working-tree inclusion, exclusions, and when the graph was generated.

For activity memory, record which material the user approved and which was rejected or redacted. Check that rejected material is absent from persistent artifacts and backups. Do not create a memory file merely because a recap was requested. Use synthetic data for automated checks.
